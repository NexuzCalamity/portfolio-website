Learning Reflection

During this Web Systems course, I learned many things like how to create a website and using other language such as HTML, CSS, JavaScript, PHP, and How to upload a repo in GitHub. I also learned how to connect each language to form a website like this portfolio. I only have a little knowledge about web development when I started Web-System subject, but now I understand how websites are designed, developed, and improved to became dynamic and interactive.

While Im working on these project and this portfolio, I experienced several challenges during development. One of the biggest challenges I encountered is fixing the errors in my code. There are a times when the layout became messy, image were not showing properly, or some buttons and animation were not working. So I add a name of every section to know what i need to add and change. I also struggled with making the website responsive because sometimes the design looked good on desktop but became broken on mobile devices. Another challenge I faced was organizing my files and section properly because I was still learning how website is being construct.

So to solve all of my website problem, I practiced checking, correcting, and debugging my code carefully to not make the problem big. I searched for solution online, watched YouTube toturials, and tested different coding techniques until the problems was fixed. I also learned to be patient and review my codes to analyzed whats the problem, because coding mistakes are just normal during developing. Instead of giving up and deleting some parts of the code that doesn't work, I continued and experiment to make it work. I mostly delete some part of my code because it was broken or not needed in my website. I also ask my friends to see my work and ask them for a feedback on how I can make my Portfolio looks cleaner and professional.

This course helped me improve my tecnical skill and my creativity, I also learned how to handle problems in developing. I realized that creating a website is not just about making it look attractive, you also need to make it functional, responsive, and easy to use.This subject inspired me to continue learning more about programming and web development because there are still many thing i need to improv and discover. I believe the knowledge and experience I gained from this course will help me improve in my career as an IT student and future developer.
